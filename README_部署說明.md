# 南特派車申請系統：部署說明

## 一、建立 Apps Script 專案（約 10 分鐘）

1. 用總務處的學校帳號開啟 https://script.google.com，點「新專案」，專案命名為「南特派車申請」。
2. 把 `Code.gs` 的內容整份貼到編輯器裡的 `程式碼.gs`。
3. 點「＋」→「HTML」，檔名輸入 `Index`（不用加 .html），把 `Index.html` 的內容整份貼上。
4. 左側「專案設定」⚙ → 勾選「在編輯器中顯示 appsscript.json」，回到編輯器，把 `appsscript.json` 的內容貼上覆蓋。
5. 上方函式選單選 `setup`，按「執行」，依畫面完成授權。
   執行完成後，雲端硬碟裡會出現下面這些東西：
   - 「南特派車行事曆」（在 Google 日曆的左側清單）
   - `派車申請系統_資料/` 資料夾，裡面有：
     - `派車申請紀錄` 試算表（分頁：申請紀錄／車輛／設定）
     - `派車申請單_範本（暫用）` Google 文件
     - `申請單/` 子資料夾（每筆申請的 Google 文件與 Word 檔都存在這裡）

## 二、填入車輛資料

打開試算表的「車輛」分頁，修改 3 台車的名稱、車牌、座位數（不含駕駛）、輪椅位。
- 修改後網頁立即生效，不必改程式。
- 某台車送修時，把「啟用」取消勾選，網頁就不會顯示這台車。

## 三、設定（試算表「設定」分頁）

- **管理者Email**：可以看全部申請、取消任何人的申請。多位用逗號分隔。
- **通知副本Email**：每筆申請成功時副本寄送，例如學務處交通車承辦人。

## 四、部署成網頁

1. 編輯器右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
2. 「執行身分」選 **我**；「誰可以存取」選 **國立臺南特殊教育學校 網域內的任何人**。
3. 按「部署」，把產生的網址（以 `/exec` 結尾）發給老師。

之後每次修改程式：「部署」→「管理部署作業」→ ✏️ → 版本選「新版本」→「部署」，網址不會變。

## 五、換成正式的 Word 範本

1. 在您的 Word 範本中，把要自動填入的位置改成下列欄位代碼（含雙大括號）：

| 代碼 | 內容 |
|---|---|
| `{{申請編號}}` | 例：P1151112-001 |
| `{{申請日期}}` | 例：115年11月12日（四） |
| `{{申請人}}`、`{{處室}}`、`{{聯絡電話}}`、`{{Email}}` | 申請人資料 |
| `{{用車時間}}` | 例：115年11月12日（四） 08:30 至 12:00 |
| `{{集合地點}}`、`{{目的地}}`、`{{事由}}` | 行程 |
| `{{一般學生}}`、`{{輪椅生}}`、`{{隨行教師}}`、`{{總人數}}` | 人數（純數字） |
| `{{車輛}}` | 例：二號車（AAA-1234） |
| `{{備註}}` | 備註 |

2. 把 Word 檔上傳到雲端硬碟 → 按右鍵「開啟工具」→「Google 文件」（會另存成一份 Google 文件）。
3. 複製該 Google 文件網址中 `/d/` 與 `/edit` 之間的 ID。
4. 在 Apps Script 編輯器最下方暫時加上一段 `function useMyTemplate(){ setTemplate('貼上ID'); }`，執行一次後即可刪除。

（也可以直接把 Word 範本交給 Claude，由 Claude 協助加上欄位代碼。）

## 六、手動擋車（保養、校內公務）

直接在「南特派車行事曆」新增活動，標題寫 **【A】保養** 這種格式（A 是車輛代號），或在標題裡寫車輛名稱（例如「一號車 驗車」），網頁就會把這台車在該時段標成「已被預約」。

## 七、讓其他人看到行事曆（選用）

Google 日曆 → 「南特派車行事曆」⋮ →「設定和共用」→ 勾選「提供給國立臺南特殊教育學校」→ 權限選「查看所有活動詳細資料」。

## 功能一覽

- 只能用學校帳號登入。
- 選好時間後，網頁即時查行事曆：可用的車輛顯示綠色，已被預約的車輛顯示紅色並列出是誰預約的。
- 依「一般學生＋隨行教師」計算座位數、依輪椅生計算輪椅位，自動推薦可以容納的車輛；一台載不下時可以勾選多台車。
- 送出時再檢查一次衝突，避免兩位老師同時預約到同一台車。
- 送出即預約成功：建立行事曆活動（也會出現在老師自己的日曆）、寫入試算表、產生 Word 申請單並寄到老師信箱。
- 「我的申請」可以重新下載 Word、列印（以 PDF 開啟列印）、在出發前取消。
- 右上角「空白申請單」可以下載空白的 Word 範本。
